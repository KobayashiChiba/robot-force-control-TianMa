# 机器人末端力控 — 正交圆柱交线分析与打磨法向量计算

## 项目摘要

本项目针对工业机器人末端力控应用中的**圆柱孔相交边缘打磨路径规划**问题，建立了两正交圆柱交线的通用几何模型，并计算沿交线各点的打磨法向量。为机器人末端执行器沿空间曲线运动时的姿态规划和力控策略提供几何基础。

## 项目背景

在机械加工中，两个圆柱孔相交处形成一条空间曲线脊线，需沿此曲线进行打磨倒角。机器人末端执行器需：

1. **精确跟踪交线路径** — 交线是三维空间曲线，非平面曲线
2. **实时调整姿态** — 打磨法向量沿曲线连续变化，末端姿态需随之调整
3. **力控策略** — 法线方向是力控的关键参考方向

本项目通过解析几何方法推导了任意两个正交圆柱的交线方程，并给出了打磨法向量的闭合形式计算公式。

## 代码介绍

核心代码为 `code/test.py`（工作目录：`e:\Code\Claude\ForceFeedback\test.py`），依赖 `numpy` 和 `matplotlib`。

### 架构

```
test.py
├── 可配置参数区    ← 圆柱半径、位置、轴线方向等均在顶部修改
├── 工具函数
│   ├── make_cylinder()  → 生成任意轴向的圆柱面 meshgrid
│   └── axis_line()      → 生成轴线端点坐标
├── 交线求解模块    ← 自动识别公共径向坐标，解出四段半曲线
├── 法向量计算模块  ← 逐点计算两个圆柱面法向量 → 角平分线
└── 绘图输出        ← 3D 可视化 + 图片保存
```

### 关键技术点

- **通用轴向支持**：基于坐标索引的集合运算，自动适配 X/Y/Z 任意轴向组合
- **四段独立绘制**：避免拼接顺序错误导致的虚假连线
- **打磨法向量**：两个圆柱面径向法向量的角平分线方向，指向金属区域
