> 创建日期：2026-08-04
> 所属项目：机器人末端力控（force_feedback_v3）

## 1. 概述

本文档描述力控系统从仿真走向生产环境时的两个关键对接点：

1. **逆推函数拟合** —— 仿真拟合的 `(Fn, Fo) → (dn, db)` 模型需替换为生产环境可用的方案，提供两个方案（A 真实数据采集 / B 仿真估计+实机微调）
2. **控制器接口** —— 生产环境只复用「力→位置修正量」的计算部分，输出逆推结果与位置偏差及混合比例，控制策略（PID/阻抗）由下游决定

## 2. 逆推方案 A：真实数据采集

### 2.1 坐标系定义

在接触曲线的**每个采样位置**建立**法平面基底** `{n, o}`：

- **n**：接触点法向，指向工件压入方向
- **o**：复法向，`o = t × n`（t 为接触曲线切向），与 n 垂直、位于法平面内
- **t**：接触曲线切向

该基底**随位置变化**——轨迹上每个点都有自己的 n、o。所有量都在这个基底里表示：

| 量 | 定义 | 范围 |
|---|---|---|
| dn | 偏移沿 n 的分量（切入深度） | ±2 mm |
| db | 偏移沿 o 的分量 | ±2 mm |
| Fn | 测量力投影到 n：Fn = F·n | — |
| Fo | 测量力投影到 o：Fo = F·o | — |

### 2.2 采集方法

**每次固定一个二维偏移向量 (dn, db)，沿标准球心轨迹独立完整跑一遍，边跑边测力。**

1. 在 ±2mm 范围内设计一组 (dn, db) 组合，例如 **5×5 = 25 个组合**：
   dn ∈ {-2, -1, 0, +1, +2}，db ∈ {-2, -1, 0, +1, +2}
2. 对每个 (dn, db) 组合：球刀沿标准球心轨迹**独立跑一圈**，球心相对接触曲线偏移 `dn·n + db·o`，姿态保持切向
3. 跑的过程中每个采样位置记录：
   - 当前位置进度 p（或弧长）
   - 该位置基底 n、o
   - 偏移量 (dn, db)（已知）
   - 测量力分解 (Fn, Fo)
4. 25 圈跑完，数据点**散布在整个法平面的网格位置**，覆盖 n 轴、o 轴和四个象限

### 2.3 数据形态与用途

```
(p, dn, db, Fn, Fo)
```

偏移和力都在法平面基底 {n, o} 里表达，同一坐标系，可直接用于拟合逆推函数 `(Fn, Fo) → (dn, db)`（沿用现有锚定二次拟合流程）。

**关键点**：偏移必须同时包含 dn 和 db 二维分量，否则采样点只落在法平面的坐标轴上（仅 n 轴或仅 o 轴），无法标定 Fo 的 db 响应与 dn·db 耦合。

### 2.4 注意事项

- 力传感器需做重力补偿（空载扫姿态拟合重力项，测量时实时扣除）
- 深压需设过载保护，大力区域可跳过
- 记录实际位姿而非指令值（机器人定位精度 ~0.05mm 会叠加误差）

## 3. 逆推方案 B：仿真估计 + 实机微调

### 3.1 思路

**不做任何离线采集/扫描实验**，直接从仿真力场热力图读出规律，估计逆推算式，直接上控制器跑，按实机效果调参。

### 3.2 初始算式（带 dn·db 耦合）

从仿真热力图观察到的规律：
- Fn 与 dn 近似线性：斜率 ≈24.5 N/mm，截距 ≈8N（目标力）
- Fo 与 db 近似线性，且受 dn 耦合影响

写成**带耦合项的代数逆推式**（纯代数解，无需迭代）：

```
dn = (|Fn| − C_FN) / K_FN
db = (Fo − K2·dn) / (K1 + K3·dn)
```

参数共 5 个：`K_FN`、`C_FN`（法向刚度/截距），`K1`、`K2`、`K3`（侧向 db 系数、dn 耦合系数、dn·db 乘积系数）。

**初值来源**：直接使用仿真拟合值（`force_field_physical_v2.py` 已拟合好的系数：K_FN=9.917, C_FN=8.0, K1=1.779/0.637, K2=-3.260, K3=2.934/1.714）。

### 3.3 调参流程

1. 初始算式和仿真系数直接进 `ForceController`
2. 实机跑起来，观察：
   - 法向力稳定性（是否稳定收敛到 8N 附近）
   - 打磨质量（切深是否均匀）
   - 限位触发情况（是否频繁触软限位/硬限位）
3. 按实机效果现场调 K_FN / K1 / K2 / K3，直到效果满意

### 3.4 优缺点

| | 方案 A | 方案 B |
|---|---|---|
| 启动成本 | 需完整采集实验（25 圈轨迹） | 零（仿真系数直接上） |
| 精度 | 真实数据，最准 | 依赖仿真与实机的接近程度 |
| 调参 | 拟合一次，无需现场调 | 需现场反复试跑调参 |
| 适用阶段 | 精度要求高的正式部署 | 快速起步、验证闭环可行性 |

## 4. 控制器接口

### 4.1 定位

生产环境只复用「力 → 位置修正量」的计算部分。新增独立模块 `force_adapter.py`（与现有 `controller.py` 分离，不破坏已验证代码），作为**力位混合预处理器**，控制策略（PID/阻抗）完全留给下游。

### 4.2 输入

- 测量力（已做重力补偿）
- 当前球心位姿
- 标准球心轨迹（离线生成）

### 4.3 内部处理

在接触曲线上找当前位姿的最近点，建立局部标架 t-n-o；把测量力投影到法平面得 Fn、Fo；Fn、Fo 经**逆推函数**（可插拔：方案 A 二次拟合 / 方案 B 带耦合代数式 / 查表）得到力控预估偏移 dn_target、db_target；同时把当前位置相对标准轨迹最近点的偏差投影到法平面，得实际位置差 dn_actual、db_actual。

### 4.4 输出

| 输出 | 含义 |
|---|---|
| d_force | 力控预估位置差 = dn_target·n + db_target·o（逆推结果） |
| d_pos | 当前位置到标准曲线的位置差 = dn_actual·n + db_actual·o |
| alpha | 力位混合比例（0~1） |
| 标架 t-n-o | 供下游按需投影 |

### 4.5 下游职责

拿到三个量后自由决定控制策略，例如：

```
d = alpha · d_force + (1 − alpha) · d_pos
```

再进自己的 PID 或阻抗控制器。alpha 默认动态计算（按位置偏差 smoothstep 混合），可设固定值。

### 4.6 实现要点

- **逆推函数可插拔**：接口接受任意 `(Fn, Fo) → (dn, db)` 函数，方案 A/B 只是不同的实现
- **最近点查询**：标准轨迹点数较多时线性扫描过慢，生产建议预建 KDTree（`lookup_inverse.py` 已有经验）
- **contact_geom 来源**：生产上从工件 CAD 或测量数据拟合圆柱 → `sample_intersection` 生成，对接时需确认由谁提供
